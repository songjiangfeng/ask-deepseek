# ask-deepseek


## 下载ollama
https://ollama.com

## 本地运行deepseek
ollama run deepseek-r1:1.5b

## 启动redis-server

## 启动php server

`git clone https://github.com/songjiangfeng/ask-deepseek.git` <br/>
`npm install` <br/>
`composer install`<br/>
`php -S localhost:9000`

## 开始交流 ask|comment(可选)
`http://localhost:9000/index.php?ask=你好&comment=你擅长什么`
